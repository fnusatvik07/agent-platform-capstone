The rules that make it real
An agent is configuration, not code
Your platform writes a document, not Python. Everything good here — versioning, safety, publishing to someone else's workspace — comes from that.
One person cannot see another's things
Make it structurally impossible, not a filter you have to remember. We will delete your application-level check and try again.
Credentials go in once and vanish
Encrypted, never in a config, never in a prompt or a log. We will search everything you stored for the token we gave you.
Risky actions ask first
Enforced by the platform, not left to the agent's instructions. And publishing strips everything internal to the company that built it.
How to use these mockups
Match the flow, not the pixels. These are pictures of what the finished product does, not a design system, and there is no starter code behind them. Build it in whatever framework you like — the nine checks you are graded against are about behaviour, not styling.
